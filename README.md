Python Trivia Game 🎮🐍

A beginner-friendly Python trivia game that tests the user's knowledge of basic Python concepts.

Features
7 Python-related trivia questions stored in a dictionary
Randomly selects 5 questions for each game using random.sample()
Takes user answers through input()
Checks answers and keeps track of the score
Displays the correct answer when the user answers incorrectly
Allows the user to play the game again
Uses functions, loops, conditions, dictionaries, lists, and the random module
Concepts Practiced

for loops • while loops • if/else • dictionaries • lists • functions • user input • random.sample() • enumerate()
